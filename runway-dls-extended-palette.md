# Runway DLS — Extended Palette

This file contains the extended colour palette (data visualisation,
category tagging, decorative accents). Core brand and semantic colours
(Grey, Purple Primary, Fuchsia, Red Error, Orange Warning, Green Success)
live in SKILL.md — do not duplicate them here.

RULE: Purple Primary (or Fuchsia for iSC) remains the only interactive
brand colour. Extended palette colours must never be used for CTAs,
active navigation, primary links, or focus rings.

---

## Usage Rules (apply to all palettes below)

- USE: 400–600 for visible accents and chart series.
- USE: 100–300 for tinted surfaces and backgrounds.
- USE: 700–900 for high-contrast text or strong emphasis where
accessibility is maintained.
- USE: One or two extended palettes within the same component, chart,
or flow to maintain clarity.
- AVOID: Using extended palette colours as the default CTA, active
navigation colour, primary link colour, or focus-ring colour.
- AVOID: Using multiple extended palettes in a way that competes with
Purple Primary or weakens hierarchy.
- AVOID: Using extended palettes as substitutes for Red Error, Orange
Warning, or Green Success when dedicated state tokens exist.
